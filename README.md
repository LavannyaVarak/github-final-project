# github-final-project

A simple interest calculator project.

This project calculates simple interest based on the principal amount, annual interest rate, and time period in years.

## Inputs

- `p`: Principal amount
- `t`: Time period in years
- `r`: Annual rate of interest in percent

## Formula

Simple Interest = (p * t * r) / 100

## Usage

Run the `simple-interest.sh` script in a Bash-compatible terminal.
